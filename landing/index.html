⚡ How It Works

Jira에서 실행 계획까지 5단계

티켓 키 하나로 전체 개발 계획을 자동 생성합니다.

01
티켓 로드
Jira API로 티켓 정보와 댓글을 직접 가져옵니다
02
AI 분석
요구사항, 인수조건, 의존성을 자동으로 추출합니다
03
계획 & PRD
구현 계획과 영향 분석 아티팩트를 생성합니다
04
검토 & 승인
계획을 검토하고 진행 여부를 결정합니다
05
실행
승인 후 구현, 테스트, 딜리버리를 진행합니다 (v0.2+)
⚡ Installation

3단계로 시작하기

플러그인 설치 → 셋업 → 시작. CLI 별도 설치 불필요.

1
플러그인 설치
Claude Code 세션에서 아래 명령을 한 줄씩 실행하세요.
# 마켓플레이스 등록
/plugin marketplace add https://github.com/ororso11/ticketpilot-claudecode

# 플러그인 설치
/plugin install ticketpilot-claudecode@ticketpilot-claudecode-marketplace
2
Jira 인증 정보 설정
터미널에서 환경변수를 설정하세요. API 토큰은 Atlassian에서 발급받으세요.
# Windows PowerShell
$env:JIRA_BASE_URL="https://your-company.atlassian.net"
$env:JIRA_EMAIL="you@example.com"
$env:JIRA_API_TOKEN="your-api-token"

# macOS / Linux
export JIRA_BASE_URL="https://your-company.atlassian.net"
export JIRA_EMAIL="you@example.com"
export JIRA_API_TOKEN="your-api-token"
3
셋업 & 시작
Claude Code에서 셋업 마법사를 실행하고 첫 티켓을 시작하세요.
# 셋업 (최초 1회)
/tp:setup

# 티켓 워크플로우 시작
/tp:start PROJ-123
⚠ 주의: 명령어는 반드시 한 줄씩 실행하세요. 여러 줄을 한 번에 붙여넣으면 URL이 합쳐져 오류가 발생합니다.
선택: HUD 상태바 설정
Claude Code settings.json 에 추가하면 실시간 상태를 확인할 수 있습니다.
{
  "statusLine": {
    "type": "command",
    "command": "node ~/.claude/plugins/ticketpilot-claudecode-marketplace/ticketpilot-claudecode/scripts/hud.js"
  }
}

🔒 Safety First

Harness 안전 시스템

AI가 안전하게 동작하도록 제어, 감시, 개선 3계층으로 보호합니다.

🛡️
제어 (Control)
위험 경로 자동 분류, Bitbucket/Bamboo CI push 차단 경고, 승인 게이트. v0.1은 코드 자동 수정 없음.
위험도 분류 Bitbucket 가드 승인 게이트
👁️
감시 (Monitoring)
모든 이벤트를 trace.jsonl에 기록. 세션 시작/종료, 도구 사용, 위험 감지를 실시간 추적.
trace.jsonl audit.log HUD 상태바
🔄
개선 (Feedback)
세션 복원, 컨텍스트 보존, 상태 자동 저장. 중단된 워크플로우를 언제든 재개할 수 있습니다.
세션 복원 상태 자동저장 컨텍스트 보존
v0.1 보장 사항
✓ 코드 파일 자동 수정 없음
✓ Jira 댓글 자동 등록 없음
✓ PR 자동 생성 없음
✓ 인증 정보 로그 저장 없음
✓ 모든 데이터 로컬 저장
✓ git push 사전 경고
